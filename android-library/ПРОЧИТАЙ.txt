Script Library — Android 10+

Исходники и автоматическая сборка находятся в ветке android-script-library репозитория segnpa66-lab/nb-scripts-authors. APK доступен в GitHub Actions, артефакт Script-Library-APK.

Свой сервер не нужен. Войдите в Null’s, обновите библиотеку; для поиска по коду нажмите «Индексировать код». Авторский список берётся из постоянной ссылки main/list.txt.

Скачивание сохраняет файлы в Download/script_library/ и удаляет почтовые адреса. Пароль сохраняется зашифрованным ключом Android только при включённом «Запомнить вход». Сессия восстанавливается автоматически, токен боя запрашивается заново при каждом запуске.

Это первая тестовая сборка. Live-операции с аккаунтом и запуск в самой игре не проверены в CI. Обновление самого APK пока вручную; для распространения обновлений понадобится постоянный ключ подписи.
