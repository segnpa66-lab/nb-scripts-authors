# Мод для раздела новостей

Обычный режим открывает `https://segnpa66-lab.github.io/` во встроенном окне игры. Это устраняет `net::ERR_FILE_NOT_FOUND`, который возникал, когда игра не устанавливала `files/index.html` по ожидаемому пути. Сайт остаётся внутри игры; внешний браузер не запускается.

Функция «Локальная страница» в настройках мода выключена по умолчанию. Включать её можно только после установки подписанного мода, если `files/index.html` действительно доступен по пути с UUID `bda43cca-1004-447d-90e6-508c41470255`. Обычный клиент требует подпись сообщества; `npm run mod` создаёт только неподписанный ZIP. Список авторов берётся из актуального `main/list.txt`. Если WebView разрешает прямые запросы к API, страница делает их сама; иначе использует существующий прокси из-за ограничений CORS сервиса.
