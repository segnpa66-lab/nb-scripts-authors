# Мод для раздела новостей

Мод меняет `SinglePageAppCommunityLaserboxUrl` на локальный `files/index.html` внутри мода. Игра открывает страницу в своём окне новостей; мод не запускает внешний браузер. Список авторов и скрипты загружаются из сети. UUID: `bda43cca-1004-447d-90e6-508c41470255`. Версия игры: 68.

Исходник для подписи — `content.json` внутри UUID-папки. Команда `npm run mod` создаёт `dist/Script-Library-unsigned.zip` с `content.json` и `files/index.html` в корне архива. Это **неподписанный** мод: для обычного клиента его нужно отправить на подпись по правилам сообщества, сохранив UUID, указанный в локальном пути. В тестовом клиенте можно установить UUID-папку как внешний источник.
