# Мод для раздела новостей

Мод меняет `SinglePageAppCommunityLaserboxUrl` на адрес веб-библиотеки. Игра открывает страницу в своём окне новостей; мод не запускает внешний браузер. UUID: `bda43cca-1004-447d-90e6-508c41470255`. Версия игры: 68.

Исходник для подписи — `content.json` внутри UUID-папки. Команда `npm run mod` создаёт `dist/Script-Library-unsigned.zip` с `content.json` в корне архива. Это **неподписанный** мод: для обычного клиента его нужно отправить на подпись по правилам сообщества. В тестовом клиенте можно установить UUID-папку как внешний источник.
